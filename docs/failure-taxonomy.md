## Regression workflow

For a recurring failure, save a deterministic input, identify whether the cause is source data, role inference, candidate placement, text fitting, scoring, or rendering, then fix the general rule. Run the focused regression, the full test suite, the official renderer, and the full benchmark before recording the updated evidence.

The latest full benchmark records 100% structural validity and determinism, zero off-canvas cases, clipping cases, image-ratio failures, and new/worsened collision cases across both suites. Pre-existing source overlaps are not counted as regressions. Docker build and offline execution passed for all three official samples; see [the Docker validation record](../evidence/docker/validation.md).
